# Alhena

An unofficial layout label editor for CharaChorder 3D input devices (CharaChorder One, CharaChorder Two, CCU and Master Forge).

## Links

- [Website](https://andy23512.github.io/alhena/)
- [Alnitak](https://andy23512.github.io/alnitak/) (Companion practice tool for CharaChorder 3D input devices)

## Features

- Draw a blank CharaChorder 3D device layout
- Assign free-text or Material icon labels to each key
- Export/import the layout as a JSON file
- Save the layout as an image, or print it
